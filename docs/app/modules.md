# 软件模块说明

本文档简要说明本软件系统的模块组成及各模块功能。

## 模块概览

本软件系统采用模块化架构，主要由以下模块组成：

- **app** - 应用程序主入口模块
- **core** - 核心上下文管理模块
- **node** - 节点管理模块
- **monitor** - 资源监控模块
- **bmc** - BMC管理模块
- **controller** - 板卡控制模块
- **alert** - 告警管理模块
- **web** - Web服务模块
- **ipmi** - IPMI通信模块
- **utils** - 工具模块

## 模块详细说明

### 1. app 模块

**功能描述：** 应用程序的主入口模块，负责整个系统的启动、初始化和生命周期管理。

**主要功能：**
- 日志系统初始化：配置spdlog日志库，支持控制台和文件输出，支持日志轮转
- 应用上下文创建：创建AppContext实例，管理HTTP服务器和所有业务模块
- 模块创建与注册：创建节点模块、监控模块、BMC模块、控制器模块和告警模块
- 信号处理：注册SIGINT和SIGTERM信号处理器，实现优雅关闭
- 主循环：运行主事件循环，保持应用程序运行直到收到停止信号
- 资源清理：在程序退出时自动清理所有模块和HTTP服务器资源

### 2. core 模块

**功能描述：** 应用上下文管理模块，负责管理整个应用程序的核心资源和生命周期。

**主要功能：**
- HTTP服务器管理：创建和配置libhv HTTP服务器，设置监听地址、端口和线程数
- HTTP服务管理：创建HttpService实例，用于注册API路由和处理HTTP请求
- 模块生命周期管理：存储和管理所有业务模块（节点、监控、BMC、控制器、告警、Web）
- 服务器启动：在独立线程中启动HTTP服务器，避免阻塞主线程
- 资源清理：提供cleanup方法，按依赖顺序停止和销毁所有模块和服务器资源
- 线程安全：使用互斥锁保护共享资源，确保多线程环境下的安全性

### 3. node 模块

**功能描述：** 节点管理模块，负责管理计算节点的信息和状态。

**主要功能：**
- 节点查询接口：提供查询所有节点、按IP查询、按机箱号查询等接口
- 节点状态管理：维护节点的基本信息和状态信息
- 告警回调：提供设置板卡类型变化告警回调的接口，当节点板卡类型发生变化时触发告警
- 接口抽象：定义INodeModule接口，隐藏具体实现细节，实现模块间的松耦合

### 4. monitor 模块

**功能描述：** 资源监控模块，负责节点资源监控和历史数据查询。

**主要功能：**
- 资源查询接口：提供查询节点最新资源快照的接口，包含CPU、内存、网络、磁盘、GPU等资源信息
- 指标序列查询：提供查询节点历史监控指标时序数据的接口，支持按时间范围和指标类型过滤
- 数据导出：提供导出节点历史数据的功能接口，用于数据分析和报表生成
- 数据接收：接收节点上报的监控数据并存储到数据库

### 5. bmc 模块

**功能描述：** BMC管理模块，负责BMC（Baseboard Management Controller）相关的数据查询和管理。

**主要功能：**
- BMC信息查询：提供查询所有机箱和指定机箱BMC信息的接口
- 板卡状态查询：提供查询板卡在位状态（PRST）的接口
- 传感器数据查询：提供查询BMC传感器最新数据和历史数据的接口
- 数据监听：监听BMC设备通过UDP多播上报的数据

### 6. controller 模块

**功能描述：** 板卡控制模块，负责机箱板卡的控制操作。

**主要功能：**
- 板卡复位：提供板卡复位操作的接口
- 板卡上电：提供板卡上电操作的接口
- 板卡下电：提供板卡下电操作的接口
- 操作结果管理：定义操作结果枚举和响应结构，包含操作结果、消息和各槽位的详细结果
- 支持批量操作：支持同时对多个槽位进行控制操作

### 7. alert 模块

**功能描述：** 告警管理模块，负责告警规则管理和告警事件生成。

**主要功能：**
- 生命周期管理：提供启动、停止告警引擎和检查运行状态的接口
- 告警规则管理：提供告警规则的增删改查接口
- 告警查询：提供按状态、过滤条件等查询告警事件的接口
- 告警创建：提供创建特定类型告警（如板卡类型变化告警）的接口
- 告警评估：定期评估告警规则，自动生成和更新告警事件
- 回调设置：提供设置告警推送回调的接口

### 8. web 模块

**功能描述：** Web服务模块，负责HTTP路由和API服务。

**主要功能：**
- 路由管理：提供设置HTTP路由的接口，将HTTP请求路由到相应的业务模块处理
- API服务：提供RESTful API接口，封装各业务模块的功能
- 依赖注入：接收HTTP服务器、HTTP服务和所有业务模块的引用，实现模块间的解耦
- 请求处理：处理HTTP请求，调用相应业务模块的接口并返回响应

### 9. ipmi 模块

**功能描述：** IPMI通信模块，提供IPMI（Intelligent Platform Management Interface）通信接口。

**主要功能：**
- IPMI连接管理：定义IPMI连接所需的配置选项（主机名、用户名、密码、权限级别等）
- 原始命令接口：提供sendRaw方法，支持发送任意IPMI原始命令
- 底层通信：封装IPMI底层通信协议，实现与BMC设备的通信

### 10. utils 模块

**功能描述：** 工具模块，提供各种通用工具函数和类。

**主要功能：**
- JSON配置管理：提供JSON配置文件的加载和访问接口，支持按点号路径访问嵌套配置
- PostgreSQL连接池：提供数据库连接池管理，支持连接复用和线程安全访问
- 时间工具：提供时间相关的工具函数，如时间戳转换、时间格式化等
- 持续时间工具：提供持续时间解析和转换的工具函数
- IP地址工具：提供IP地址相关的工具函数
- 多播扫描：提供网络多播扫描功能
- 响应构建：提供HTTP响应构建的工具函数

## 模块依赖关系

```
app
 ├── core (应用上下文)
 │   ├── web (Web服务)
 │   │   ├── node (节点管理)
 │   │   ├── monitor (资源监控)
 │   │   ├── bmc (BMC管理)
 │   │   ├── controller (板卡控制)
 │   │   └── alert (告警管理)
 │   ├── node
 │   ├── monitor
 │   ├── bmc
 │   ├── controller
 │   └── alert
 └── utils (工具模块，被各模块使用)
```

## 技术栈

- **HTTP服务器：** libhv
- **日志库：** spdlog
- **数据库：** PostgreSQL (通过libpqxx)
- **JSON处理：** nlohmann/json
- **IPMI通信：** libfreeipmi
- **事件处理：** eventpp
